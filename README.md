## What is CipherKit?
CipherKit is a desktop application that makes encoding and decoding text fast and approachable. It focuses on usability and teaching: each cipher includes clear parameter inputs (keys, shifts, alphabets) and short descriptions so you can understand how the transformation works.

CipherKit is ideal when you want to:
- Learn how classical ciphers operate (Caesar, Morse, Atbash, etc.).
- Prototype simple text transformations and obfuscation for educational or hobby projects.
- Work offline — no cloud upload required.
  
## Key features
- Encode and decode text with a single click.
- Real-time preview of results as parameters change.
- Import/export results as plain text files.
- Clear parameter controls and short help text for each cipher.

## Supported ciphers
CipherKit includes a broad selection of classical ciphers. Typical examples include:
- Morse (with audio)
- Atbash
- Caesar
- Gronsfeld
- Railfence
